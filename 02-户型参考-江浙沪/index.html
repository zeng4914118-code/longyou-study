北厅补充（2026-10-30）

事实新增 北厅（江景） 页：共 9 例北厅户型图（140–150 段 4、155–170 段 3、185 段 2）；只有 N1 已证实两梯两户，其余梯户比未核实。另列 3 条梯户比未核实或年份偏早的线索。推断近两年江浙沪北厅大多出现在“北侧临江/湖”的楼栋，并且多是 140㎡ 以上的边套。

先说结论（本版已按新标准重做）

  1. 事实成都案例已移出（存档在 _archive-成都/，不再链接）。只收江浙沪，且梯户比必须有出处，证实是一梯两户或两梯两户；两梯三户、两梯四户以及无法核实的一律剔除。
  2. 事实通过的只有 7 例（6 例带图）：120㎡ 1 例、130㎡ 0 例、148㎡ 3 例、168㎡ 3 例。城市以杭州为主，另有苏州 1 例。
  3. 推断在大城市的高层盘里，120–130㎡ 多半是两梯三户或两梯四户（如鸣澜里 120、云杭里 127、荷语江山府 129），两梯两户一般只给 139㎡ 以上的边套或楼王。所以 120–130 段很难找到“已证实两梯两户”的近两年案例。龙游 FAR 1.6 做小高层/洋房，反而容易做到全盘两梯两户/一梯两户，这本身就是卖点。
  4. 未知得房率：只有 J1 云杭里 119 有套内面积（约 89%）；其余是开发商或项目口径，或者未核实。
  5. 建议可借鉴的点：120 做“三房+灵动书房 + 6m 边厅 + 独立电梯前厅”（J1）；148 做“子母门玄关 + 14m 四开间 + LDK”（J2）；168 做“五开间朝南 + 双套房 + 中西厨 + 约 7.35m 方厅”（J5/J7）；收纳指标化（J6 约 25,540L）可直接写进任务书。

北厅户型（项目北侧衢江江景）

结论

  1. 事实北厅案例同样执行“已证实一梯两户/两梯两户”的标准。北厅案例共 9 例、9 张户型图：140–150 段 4、155–170 段 3、185 段 2；其中只有 N1 已证实两梯两户，N2–N9 梯户比标为未核实（按本轮“可放宽”的要求收录）。120 / 130 段 0。
  2. 推断北厅在江浙沪是少数派：大多数项目宁可放弃北侧景观，也要保客厅朝南。只有“北侧一线江/湖”的楼栋会做北厅，常见做法是“四房朝南 + 北向转角大厅”，面积多在 140㎡ 以上。
  3. 建议龙游北侧临衢江，建议只在北排一线楼栋做北厅版本：卧室全部朝南保日照，客餐厅一体放北侧，用转角窗或通高玻璃面向江面，面宽≥7m（参照 N1 及线索 N4/N5 建发望江 143 的约 11m 江景面）。南排楼栋仍用 J1–J7 的南厅户型。
  4. 建议需要关注：北厅冬季没有日照，要靠南侧卧室和阳台补；北向大玻璃要做好保温（参照浙江节能要求）；江面西晒和眩光可用转角挑檐处理。
