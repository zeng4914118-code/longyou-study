先说结论（本版已按新标准重做）

  1. 事实成都案例已移出（存档在 _archive-成都/，不再链接）。只收江浙沪，且梯户比必须有出处，证实是一梯两户或两梯两户；两梯三户、两梯四户以及无法核实的一律剔除。
  2. 事实通过的只有 7 例（6 例带图）：120㎡ 1 例、130㎡ 0 例、148㎡ 3 例、168㎡ 3 例。城市以杭州为主，另有苏州 1 例。
  3. 推断在大城市的高层盘里，120–130㎡ 多半是两梯三户或两梯四户（如鸣澜里 120、云杭里 127、荷语江山府 129），两梯两户一般只给 139㎡ 以上的边套或楼王。所以 120–130 段很难找到“已证实两梯两户”的近两年案例。龙游 FAR 1.6 做小高层/洋房，反而容易做到全盘两梯两户/一梯两户，这本身就是卖点。
  4. 未知得房率：只有 J1 云杭里 119 有套内面积（约 89%）；其余是开发商或项目口径，或者未核实。
  5. 建议可借鉴的点：120 做“三房+灵动书房 + 6m 边厅 + 独立电梯前厅”（J1）；148 做“子母门玄关 + 14m 四开间 + LDK”（J2）；168 做“五开间朝南 + 双套房 + 中西厨 + 约 7.35m 方厅”（J5/J7）；收纳指标化（J6 约 25,540L）可直接写进任务书。
